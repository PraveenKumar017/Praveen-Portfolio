01 / About

Engineered for clean code, built for real products

I'm a Senior Software Engineer with 2.5+ years of experience specializing in Angular, TypeScript, and modern responsive web development — building scalable applications and reusable UI components for enterprise products. My core stack spans Angular, TypeScript, HTML5, CSS3, and JavaScript on the frontend, with working knowledge of Go, MySQL, Cassandra, and REST APIs on the backend — so I can debug and reason about issues across the full stack rather than just the UI layer.

At Algomox, I've built interfaces for complex enterprise systems — OS image management and remote monitoring tools, plus endpoint security features within a Data Loss Prevention framework — bringing hands-on experience in performance optimization, clean architecture, and designing interfaces that stay usable as products scale.

Outside my core role, I take on freelance projects end-to-end — design, development, and deployment — and keep sharpening my UI/UX design skills with tools like Figma. I enjoy staying hands-on with new technologies, treating every project, big or small, as a chance to sharpen how I build.
